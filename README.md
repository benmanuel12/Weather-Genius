# Weather-Genius

This was planned to be a project which aggregated multiple sources of weather data and then used algorithms and machine learning to approximate a better forecast, then display it on the page.
However, I was not aware of the cost of acquiring that amount of live, or sufficiently up to date data and cloud computing space to do all that for what amounted to a teenager's hobby project.
What is in this repository is the beginnings of the webpage.

Some of the idea was carried forward into a university project (https://github.com/benmanuel12/Data-Visualisation-Website) whereby using old Met Office data and cloud computing credits offered by the university I was able to do some machine learning on weather data, but in the real world, a project like this would need to be able to make money to pay off the data feed costs and server costs, I think

## Built with
HTML, CSS, JavaScript, Node.JS

## Features
- Webpage running on Node.JS server

## Running it
- node index.js
